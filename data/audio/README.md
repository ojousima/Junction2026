# data/audio

Audio for Edge Impulse training and testing. Only this README and the folder
structure are in git; the WAV files and raw downloads are git-ignored.

Fetch the public data (about 2.5 GB download, needs `ffmpeg`):

```bash
python3 tools/fetch_audio.py
```

All clips are converted to 16 kHz mono 16-bit WAV, the same format the UNO Q mic
pipeline uses. Raw downloads are cached in `raw/`, so re-runs only convert.
`--per-class N` changes the subset size and `--only <source>` fetches one source.

## Layout

```
data/audio/
  candas/        small DC cooling fans, magnets on blades (imbalance)
    training/normal/   balanced fan (config 1)
    testing/normal/    held-out balanced clips
    testing/anomaly/   configs 2..5, light to severe imbalance
  mimii_fan/     industrial fans with factory noise (DCASE 2020 Task 2)
    training/normal/  testing/normal/  testing/anomaly/
  rig/           OUR recordings, same layout
    training/normal/   healthy outdoor units, one file per unit (any format ffmpeg reads):
                       Autotalli-ilp, Keittiö-ILP (team phone recordings),
                       Mitsubishi-ulkoyksikko (Svante's videos, 9 s),
                       freesound-701332-ac-heatpump (fetched by tools/fetch_audio.py)
    other/             other machines a unit model must not accept: ILP indoor unit
                       (Svante's video)
    svante/            original videos + extracted audio and frames
    augmented/         generated by tools/rig_augment.py (see below)
  heatpump_ref/  real air-to-water heat pump, healthy (RWTH listening test)
  noise/         background noise: 16 ESC-50 classes (traffic, aircraft, helicopter,
                 rain, wind, dogs, ...) + Mini LibriSpeech speech
  raw/           download cache
```

File names carry the source and the condition, for example
`candas_A3_9V_cfg5_abnormal_000123.wav` (fan A3, 9 V supply, imbalance config 5).

## How to use it

Anomaly detection only needs healthy sound. Train on `training/normal`, then check
that `testing/anomaly` scores higher than `testing/normal`. Keep one Edge Impulse
project per source: public fans validate the method, `rig/` is the model we deploy.

```bash
npm install -g edge-impulse-cli
edge-impulse-uploader --category training --label normal  data/audio/candas/training/normal/*.wav
edge-impulse-uploader --category testing  --label normal  data/audio/candas/testing/normal/*.wav
edge-impulse-uploader --category testing  --label anomaly data/audio/candas/testing/anomaly/*.wav
```

In Edge Impulse: Spectral Analysis block (log spectrum, FFT 64-512), then a GMM or
K-means anomaly block trained on `normal` only. The MFE block does not work with the
GMM block (its 2D output breaks training). `heatpump_ref/` is for listening and the pitch.

## Rig data: noise augmentation and synthetic faults

A few minutes of healthy audio per outdoor unit is enough to start, if we stretch it:

```bash
.venv/bin/python tools/rig_augment.py   # writes rig/augmented/{training,testing}/...
.venv/bin/python tools/eval_rig.py      # compares feature sets, prints AUC per fault
```

- Healthy audio + background noise (−5..20 dB SNR) is still healthy, so the model
  learns to ignore cars, aircraft and people talking.
- Faults are synthesised from heat pump physics and used for testing only: fan
  imbalance (airflow noise modulated at the rotation rate), loose-mount rattle,
  fan rub (something touching the blades: a scrape at the blade-pass rate), fan and
  compressor bearing wear (resonance impulses at ~3.2 x shaft speed, the outer-race
  defect order), blocked coil (fan and compressor faster, airflow louder) and a
  compressor electrical/valve defect (extra sub/inter-harmonic line). Defect rates are
  set in orders of the shaft speed, and the compressor speed is found from its harmonic
  series, so the same fault models apply to any unit.
- Each unit's recording is split in time (first 70 % train, last 30 % test) and noise
  clips are split by file, so tests use audio and noise the model has not seen.

File names carry unit, condition, noise and SNR, for example
`Autotalli-ilp_imbalance_speech+4dB_012.wav`. Physics features live in
`python/physics_features.py` (numpy only, runs on the UNO Q).
